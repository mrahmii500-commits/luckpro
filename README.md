# Luck Pro

A frontend starter for a transparent rewards/referral website.

## Included
- Landing page
- Login/signup UI
- Referral-code link generation
- Member dashboard
- Points/tasks demo
- Admin dashboard UI
- Responsive CSS

## Important
This starter uses browser localStorage only. It is **not production authentication** and should not be used to hold real money or sensitive user data.

For production:
1. Use server-side authentication.
2. Use a real database.
3. Validate referral codes on the server.
4. Keep an immutable points/transactions ledger.
5. Add admin authorization and audit logs.
6. Publish clear reward, privacy, and terms policies.
7. Do not add betting, wagering, deposits, or chance-based money games.
